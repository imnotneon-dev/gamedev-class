## Scene & VFX Overview

Built on a separate branch and scene using Unity's built-in Particle System and unlit additive materials, this showcase features two multi-layered 3D visual effects: a **Magical Girl Transformation VFX** and a **Final Boss Auramaxxing VFX**.

### Key Particle Systems & Configurations

- **Girl Transformation VFX (`MagicalGirlTransform_VFX`):** Starts off with multiple (`box`) shaped particle systems to show 6 rays behind the character then the aura starts to build and a forcefield to complete the transformation.
- **Final Boss Auramaxxing VFX (`FinalBossAura_VFX`):** Starts off emmitting small lightning rays, then suddenly, a sphere of lighting appears out of nowhere with the character's area being lit up with blue light, then boom! Longer lightning rays come out of nowhere with a spiral background forming from the character.
