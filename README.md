## Level Overview

This project is a 3D platform obby inspired by Roblox obbies. The level features a sequential path with progressive difficulty, requiring players to rotate, vertically shift, and horizontally move platforms.
- **Blue Platforms:** Rotation
- **Pink Platforms:** Vertical
- **Grayscale Platforms:** Horizontal (Left-Right only)
